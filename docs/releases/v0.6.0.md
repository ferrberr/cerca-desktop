Aplicación de escritorio para Windows y Linux, con IA local, búsqueda de productos, filtrado estricto, alertas y mapa.

## Descargas

- **Windows x64:** `Cerca-0.6.0-windows-x64-setup.exe`.
- **Linux x64:** `Cerca-0.6.0-linux-x64.AppImage` o `Cerca-0.6.0-linux-x64.deb`.
- `SHA256SUMS` permite comprobar la integridad de los tres instaladores.

## Primer arranque

1. Instala y abre Cerca. No hace falta Node.js ni un navegador para la interfaz.
2. En el asistente **Configurar IA local**, abre la descarga oficial de Ollama, instálalo y déjalo abierto.
3. Pulsa **Descargar modelos**. Se descargan aproximadamente 13 GB y se reutilizan los pesos que ya estén instalados. Puedes cancelar y reanudar.
4. Busca productos, configura precio mínimo/máximo, estado y ubicación, o utiliza el mapa.

Se recomienda disponer de 24–32 GB de RAM. Una GPU compatible mejora la velocidad. Las consultas de anuncios y mapas necesitan Internet; la inferencia se ejecuta localmente. Las alertas funcionan mientras Cerca esté abierta.

Los instaladores incluyen Electron 45.3.2. Los modelos gratuitos Nimble 9B, Qwen3.5 9B y Qwen3 Embedding 0.6B se descargan por separado con Ollama 0.35.0 o posterior. No se incluyen anuncios consultados ni datos personales en el instalador.

Esta versión no dispone de firma comercial de código de Windows. La descarga está publicada en el repositorio `ferrberr/cerca-desktop`; el fichero `SHA256SUMS` identifica los archivos de esta versión.
